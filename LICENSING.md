## Distributing a release

Provide the plugin's Corresponding Source under these terms when distributing
the compiled plugin. For a GitHub release, publish the complete corresponding
source and build scripts in the exact release tag alongside the binary assets,
with equivalent access to the source archive. Include any modifications that
produced the distributed build.

The packaged release includes the licensing documents. The main.js build banner
also contains the GPL text, host permission and third-party notices, so the
licensing material accompanies installations made through Obsidian's three-file
download mechanism.
